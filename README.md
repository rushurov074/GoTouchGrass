# GoTouchGrass
This is a Slack bot hosted in Hack Club's workspace. It is meant to log/track runs, mileage, and minutes. 

- /go-touch-grass-log [miles] [minutes] will log the number of miles and minutes, as well as automatically save the date and time.
- /go-touch-grass-view displays all of the runs you have saved
- /go-touch-grass-delete allows you to delete one of your logs from a list
- /go-touch-grass-help displays the commands you can use
